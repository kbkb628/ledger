# 痛点分析：为什么「叙事知情一致性」值得单独做一个产品

> 结论先行：**「一致性」已经被行业公开点名为 AI 短剧商业化的瓶颈，但公开讨论几乎都停在画面层（脸、道具、场景）；真正让人弃剧、让制作方返工的，是更隐形的一层 —— 角色知道了她当时不可能知道的事。** 这一层没有现成工具，也最容易被上下文窗口和人工记忆漏掉。

## 一、行业已经不是"猜"这个痛点了

1. **证券时报 · 21世纪经济报道（2025-12-16）**《AI视频进入"连续叙事"时代："一致性"成商业化发展瓶颈》：
   > "真正的挑战并不在一帧画面的逼真度，而在十集、二十集剧情推进中——角色是否『还是那个人』？场景是否『仍在同一个世界』？"
   > "观众可以容忍一集画质稍逊，却无法接受主角在第二集『换脸』，或关键道具凭空消失。而『主体不一致』问题，在多集内容中被急剧放大，成为制约AI短剧商业化的瓶颈。"
   > 商汤 Seko 产品负责人：“一旦这些要素断裂，观众便会因违和感而脱离剧情沉浸，就不愿意为这样的场景买单。”
   链接：https://stcn.com/article/detail/3542006.html

2. **36氪（2025-12-25）**《攻克长视频生成记忆难题：港大与快手可灵 MemFlow……告别快速遗忘与剧情错乱》：
   > "一个角色暂时离开画面后再次出现，却『面目全非』，仿佛换了演员……这种『金鱼记忆』式的顽疾，正是长视频生成在叙事上的一大致命伤。"
   链接：https://www.c114.net.cn/industry/47554.html

3. 同一时期，学界把 **long-video storytelling 的"一致性"** 直接写进综述与会议议题（如 *A Survey on Long-Video Storytelling Generation: Architectures, Consistency, and Cinematic Quality*；ICML 2026 的 DynaMem/Long-video memory 方向），说明「记忆/一致性」是当前公认的开放难题。

**三条证据的共同点**：都承认"一致性"是**商业化门槛**；都把它当**记忆问题**来解（记忆机制、角色锁定、视觉记忆）。

**它们的空白**：解决的是 **"看起来是不是同一个人/同一个世界"**；没有回答 **"这个人此刻该不该知道这件事"**。

## 二、为什么"知情一致性"更贵

| 维度 | 画面不一致（已被大量解决） | 知情不一致（本项目） |
|---|---|---|
| 观众反应 | "这演员换了" → 出戏 | "她怎么知道的？" → **觉得被糊弄，弃剧** |
| 谁会发现 | 剪辑/观众，肉眼可见 | 只有**记得前情**的观众；越忠实越先发现 |
| 修复成本 | 局部重绘/重生成 | 台词引发的情节逻辑要**重写整条线**（第 27 集错，前 20 集埋的伏笔全废） |
| 什么时候最痛 | 单镜头 | **连载到十几集以后**，改一集要重拍 |
| 现有工具 | 生成侧一致性（角色锁定、记忆机制） | **无**：没有"知识状态"这一层的数据结构 |

一句话：**画面不一致让人出戏，知情不一致让人不信。** 后者直接打击"要不要继续追"。

## 三、为什么现有三种做法都接不住

1. **纯文档 / 提示词约定（含 skill 类方案）**：判据是"希望模型自觉读规范"。读没读、读到哪一段，不可验证；落笔那一刻**没有任何强制点**。
2. **大模型逐句校准**：让模型每次重读剧本再判断。问题是上下文随集数增长、成本与延迟随之爆炸，且**结论不落盘**（同问可能两答），没法审计、没法复用、没法解释"为什么拦这一条"。
3. **生成侧一致性**：解决脸、服装、道具的连续性，**完全不涉及"谁知道什么"**；剧本写得再自洽，也拦不住台词层面的事实错误。

## 四、我们的产品假设（可被证伪）

> **假设 H**：把"谁、在第几场、知道了什么"从剧本里抽出来、冻结成可查可写的账本，就能在落笔前用**零模型调用**的方式拦住绝大多数知情穿帮，并且误报率能压到**个位数百分比**。

可验证指标（都在仓库里可复现）：
- `real` 误报率：两本专业剧本分别 **7/269 = 2.6%**、**7/165 = 4.2%**（零标注，剧本自洽 ⇒ 报出即误报）；
- `dev` 召回/精确率：P 50% / R 30%（10 条注入标注，分辨率有限）；
- 机制探针：同义改写泄漏 **1/8**、沿用原句 **7/8** —— 明确指出"说法匹配"是当前主瓶颈。

## 五、什么情况下这个产品**没必要**（写清楚，避免过度推销）

- 单集、短时长、非连载内容（一致性压力小，人工记得住）；
- 已经有一份被严格执行的"人物档案 + 时间线"且写手规模 ≤1（人能兜住）；
- 只需要"画面一致"，不需要台词层面的逻辑自洽（生成侧方案足够）。

## 六、结论

痛点有三重证据（行业公开报道、学术议程、修复成本结构），且现有方案各有断层：
**文档缺强制点、大模型缺可复现与成本、生成侧缺知情层**。
所以把"知情一致性"做成一个**独立的、可复现的、能挂进 agent 的账本**是有必要的 ——
它的价值不在"比大模型更聪明"，而在**可查、可复现、可审计、能嵌进写作流程的落笔瞬间**。
