# 5 分钟演示片（拍摄说明 + 逐镜文案）

> 产物：`docs/demo-film.html` —— 一个**自动播放**的单页影片（9 个镜头，总长约 4 分 35 秒）。
> 用浏览器全屏录制它就是成片主体；只有镜头 6（真 agent 拦截）需要你在 DSH 里现场操作一下。
> 线上地址（推上去就有）：https://kbkb628.github.io/ledger/demo-film.html

## 为什么做成「一个会自动播的页面」

- **可复现**：镜头、字幕、数字都写死在页面里，不会像现场打命令那样因为网络/模型抖动演砸。
- **可重录**：按 `R` 重播，按 `空格` 暂停，`←/→` 切镜 —— 录坏了不用重来一遍准备。
- **无外部依赖**：单文件、无外链字体和图片，断网也能播。

## 录制步骤（约 15 分钟）

1. 打开 `docs/demo-film.html`（本地 `file://` 或线上 Pages 均可），**F11 全屏**，把窗口调成 16:9。
2. 录制工具：Windows 自带 `Win+Alt+R`（Xbox Game Bar）即可；要更干净用 OBS（录显示器采集，60fps）。
3. 按 `R` 重播，从头录到片尾（约 4 分 35 秒）。
4. **镜头 6（3:30 左右）留了个现场位**：在 DSH 里让 agent 调一次 `mcp__ledger__ledger_check`
   （`line="你三年前在码头做了什么？"`, `character=沈知微`, `scene=S02-02`），拿到 `leak: true` 的那一屏。
   录完把它剪进 3:30–4:00 之间；或者干脆把这段单独录 20 秒作为 B-roll。
5. 配音两种都行：
   - **字幕版**（最省事）：页面底部已经写好每镜的旁白字幕，直接录屏即可；
   - **配音版**：照下面的逐镜文案念，剪掉页面字幕（把 `#cap` 那段 CSS 删掉即可）。
6. 上传前自查：画面里不出现 `.env`、绝对路径、真 key；时长 ≤5 分钟。

## 逐镜文案（也是页面字幕）

| 时间 | 镜头 | 旁白 / 字幕 |
|---|---|---|
| 0:00–0:12 | 片头 | 《账本》—— 一个挂在写稿 agent 上的叙事一致性账本：它只回答一个问题，这个角色此刻该知道这件事吗。 |
| 0:12–0:38 | 问题 | 续写型创作的硬伤不是文笔，是一致性：谁在第几集知道了什么。观众记得，剧本没记。 |
| 0:38–1:08 | 它是什么 | 账本把「谁在何时得知了什么」从剧本里抽出来、冻结成一本可查的账；写稿时按账放行或拦截。 |
| 1:08–2:03 | 真机运行 | 下面每一行都是真实运行：建账、拦住、放过、审计、豁免。 |
| 2:03–2:45 | 三种判定 | 关键不是「报了多少条」，是这三种判定都用同一本账算出来：拦住、放过、命中但已知情。 |
| 2:45–3:15 | 审计 + 豁免 | 整本审计给清单，每条都带成因；误报用 waive 记一笔，清单当场少一条。 |
| 3:15–3:45 | 数字 | 所有数字带版本戳和区间，三套测试集互不可比 —— 这是它和「感觉还行」的区别。 |
| 3:45–4:10 | 边界 | 它的边界也说清楚：封闭世界假设会带来误报，所以豁免是产品的一部分，不是补丁。 |
| 4:10–4:35 | 片尾 | 仓库、在线演示、可安装的 MCP server。MIT。 |

## 一句话卖点（口播版，30 秒）

> AI 短剧最贵的 bug，是「她怎么知道的」。
> 账本把 80 集里「谁在第几集知道什么」抽出来冻结成账；写作 agent 落笔之前查一次，
> 该拦的拦住，该放的放过，误报一键豁免。
> 建账 14 秒，查一句话不调模型，MCP 一行配置就能挂到你自己的 agent 上。
