写稿时的三个瞬间

    
拦住该拦的，放过该放的

    

      

        
⛔ 拦住

        
line「你三年前在码头做了什么？」
character 沈知微 · scene S02-02

        
→ 陆见深三年前在码头做了某件事
全剧没有记录 沈知微 得知过这条命题

      

      

        
✅ 放过

        
line「这块表你收好。」
character 沈知微 · scene S01-03

        
→ 命中 0 条命题
这句话不承载任何秘密

      

      

        
✅ 命中但已知情

        
line「老爷留下的那份东西，如今在谁手上？」
character 苏婉 · scene S04-03

        
→ 命中 1 条命题
说话人在这一场已知情（或已豁免）

边界

    
它不假装全知

    

      账本只认剧本里写过的「谁何时知道」。于是「公众都该知道的事实」会被当成秘密 —— 

      这正是 ledger_waive 存在的理由：豁免一条，记一条理由，进判决流水。


      已知不可解的一类：「在问细节」与「在暗示自己知道」词法上不可分，
      三次尝试（词表 / 判定层 / 问句）都失败并留下了记录。
